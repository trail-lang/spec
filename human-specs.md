This document provides links to official specifications for major object-oriented programming languages. These references are useful for comparing TRAIL semantics and ensuring completeness when designing or reviewing the TRAIL language.

## Official Language Specifications

- [C# Language Specification](https://learn.microsoft.com/dotnet/csharp/language-reference/language-specification/)
- [Java Language Specification](https://docs.oracle.com/javase/specs/)
- [Kotlin Language Reference](https://kotlinlang.org/docs/reference/)
- [Swift Language Reference](https://docs.swift.org/swift-book/documentation/the-swift-programming-language/)
- [TypeScript Specification](https://github.com/microsoft/TypeScript/blob/main/doc/spec-ARCHIVED.md)
- [C++ Standard Drafts](https://eel.is/c++draft/)
- [Go Language Specification](https://go.dev/ref/spec)
- [Rust Reference](https://doc.rust-lang.org/reference/)
- [Scala Language Specification](https://www.scala-lang.org/files/archive/spec/2.13/)
- [PHP Language Specification](https://www.php.net/manual/en/langref.php)

These links provide authoritative references for language features, object models, and design patterns relevant to TRAIL's goals.
