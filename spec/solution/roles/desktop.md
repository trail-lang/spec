# `desktop`

Represents a native desktop application target (Windows, macOS, Linux) with a
GUI shell.

## Characteristics

- Entry point: executable or app bundle with a main window loop.
- Integration points: OS-specific APIs, local storage, possible offline modes.
- Distribution: installers, app stores, or enterprise deployment channels.

## Usage Notes

- Desktop apps can be `owned` or `dependency` depending on who maintains the
  codebase.
- Document UI frameworks, packaging formats, and update strategies in the app's
  detailed specification.
