# `mobile`

Represents a native or hybrid mobile application (iOS, Android, cross-platform
stacks).

## Characteristics

- Entry point: mobile app bundle with lifecycle hooks (launch, background,
  resume).
- Integrates with device capabilities: push notifications, sensors, secure
  storage.
- Distribution through app stores or enterprise mobile management tools.

## Usage Notes

- Mobile roles may appear as `owned` or `dependency` depending on who publishes
  the app.
- API contracts, offline sync, and analytics requirements belong in the app's
  detailed documentation.
