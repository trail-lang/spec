# Solution Roles

This directory defines the role keywords that may appear in `owned <role>` or
`dependency <role>` statements inside `solution.trail`.


## Valid Roles

- [`api`](api.md) — backend application tiers.
- [`spa`](spa.md) — browser-based frontends.
- [`worker`](worker.md) — background job processors.
- [`rdbms`](rdbms.md) — relational databases.
- [`queue`](queue.md) — message queues.
- [`storage`](storage.md) — blob/object storage.
- [`bus`](bus.md) — event bus or streaming backbones.
- [`cache`](cache.md) — distributed caches.
- [`kv`](kv.md) — key-value stores.
- [`nosql`](nosql.md) — document/column/graph databases.
- [`desktop`](desktop.md) — native desktop applications.
- [`mobile`](mobile.md) — native or hybrid mobile apps.
