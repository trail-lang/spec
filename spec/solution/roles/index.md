# Solution Roles

This directory defines the role keywords that may appear in `owned <role>` or
`dependency <role>` statements inside `solution.trail`.

## Available Role Docs

- `api.md` — backend application tiers.
- `spa.md` — browser-based frontends.
- `worker.md` — background job processors.
- `rdbms.md` — relational databases.
- `queue.md` — message queues.
- `storage.md` — blob/object storage.
- `bus.md` — event bus or streaming backbones.
- `cache.md` — distributed caches.
- `kv.md` — key-value stores.
- `nosql.md` — document/column/graph databases.
- `desktop.md` — native desktop applications.
- `mobile.md` — native or hybrid mobile apps.

Additional roles can be added over time by creating new files within this
directory.
