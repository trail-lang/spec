# Solution Roles

This directory defines the role keywords that may appear in `owned <role>` or
`dependency <role>` statements inside `solution.trail`.


## Available Role Docs

- [`api.md`](api.md) — backend application tiers.
- [`spa.md`](spa.md) — browser-based frontends.
- [`worker.md`](worker.md) — background job processors.
- [`rdbms.md`](rdbms.md) — relational databases.
- [`queue.md`](queue.md) — message queues.
- [`storage.md`](storage.md) — blob/object storage.
- [`bus.md`](bus.md) — event bus or streaming backbones.
- [`cache.md`](cache.md) — distributed caches.
- [`kv.md`](kv.md) — key-value stores.
- [`nosql.md`](nosql.md) — document/column/graph databases.
- [`desktop.md`](desktop.md) — native desktop applications.
- [`mobile.md`](mobile.md) — native or hybrid mobile apps.

Additional roles can be added over time by creating new files within this
directory.
