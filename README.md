This repository contains the evolving specification for **TRAIL** (Topology & Runtime Architecture Intent Language).
This is a specification for a language that is more AI friendly than traditional langauges like C#, Java, PHP, etc.

It will achieve this by:
- minimising tokens needed to express code and infrastructure
- signaling intent in every aspect of expression
- defining what is not controlled/coded by the LLM so that it may better understand the whole ecosystem


The scope of the language is not just another set of code syntax. By signaling intent in every aspect of the language itself, we can describe:
- [Infrastructure](spec/solution.md)
- [Solution Architecture](spec/solution.md)
- [Code](spec/index.md)
